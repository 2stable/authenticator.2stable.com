How do I import accounts from Google Authenticator?

If you’ve already set up two-factor authentication (2FA) codes in Google Authenticator, you can easily bring them into the Authenticator App by 2Stabel using the add form Google option. This is useful if you’re switching devices or want to manage all your 2FA codes in one app.

Here’s how to do it using Google Authenticator:

  1. Open Google Authenticator.

  2. Export your accounts:
    Tap the overflow button (three-dots icon) in the top-right corner and select Export accounts.

  3. Select accounts to export:
    Select the accounts you want to move to the Authenticator App. Google Authenticator will generate a QR code containing the selected accounts.

  4. Import into the Authenticator App:
    Open the Authenticator App and tap the + (plus) icon.
    Select the Google import option.
    • From another device: Scan the QR code generated by Google Authenticator.
    • From the same device: Take a screenshot of the QR code, save it to your Photos or Files, then choose Import from Files in the Google option.
  5. Confirm your accounts:
    Once imported, the Authenticator App will start generating codes for each account automatically. You can verify that both apps are generating the same codes.

ℹ️ Tip: The add from Google option is only for accounts already set up in Google Authenticator. For new accounts, use QR codes or secret keys to link them directly to the Authenticator App. Learn more here.
